## ❓ NON SAI COSA HAI?

### Scopri il tuo sistema operativo:

#### **Windows**
- Hai una GUI (interfaccia grafica) con Start menu
- File Explorer
- Estensioni `.exe`, `.msi`
- Cartelle: `C:\`, `Program Files`

#### **Linux**
- Spesso solo terminale (riga di comando)
- Ubuntu, Debian, CentOS
- Comandi: `ls`, `cd`, `apt`
- Cartelle: `/home`, `/var`, `/etc`
