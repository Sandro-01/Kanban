# 🔄 Nuovo Workflow Onboarding Integrato

## 📋 Panoramica

Il processo di onboarding è ora **completamente integrato** nel sistema Kanban ISO.
Non serve più inviare email a helpdesk@carton-group.com - tutto avviene tramite il sistema!

---

## 🎯 Come Funziona

### 1️⃣ HR Crea l'Onboarding

**Chi:** HR (o Manager con permessi)
**Dove:** Sezione "Onboarding" → Pulsante "Nuovo Onboarding"

**Compila il form con:**

#### 📋 Informazioni di Base
- Nuovo Dipendente (seleziona dalla lista utenti)
- Manager Responsabile
- Data Inizio e Data Prevista Completamento
- Sede, Reparto, Ruolo/Mansione

#### 💻 Dotazioni Hardware
- Computer: Portatile / Desktop / Non necessario
- Telefono: Fisso / Android / Non necessario
- ☑ Cuffie
- ☑ Webcam
- ☑ Schermo aggiuntivo

#### 🔐 Software e Accessi
- ☑ Pacchetto Microsoft 365
- Software Specifici: PackWay, HubSpot, ArtiosCAD, AutoCAD, etc.
- Accessi Sistemi: VPN, cartelle condivise, ERP, CRM, etc.

#### 📝 Note Aggiuntive
- Mouse wireless, tastiera meccanica, licenze speciali, etc.

---

### 2️⃣ Sistema Crea Ticket Automatico

**Cosa succede:**

✅ Appena crei l'onboarding, il sistema genera **automaticamente un ticket** per IT:

**Titolo:**
`🆕 Onboarding: [Nome Cognome] - Preparazione Dotazioni`

**Assegnato a:**
Reparto IT

**Priorità:**
HIGH (24h SLA)

**Categoria:**
Richiesta Onboarding

**Descrizione Include:**
- Tutte le informazioni del dipendente
- Lista dettagliata dotazioni hardware
- Software e accessi necessari
- Note aggiuntive del responsabile
- Data entro cui preparare tutto
- Link all'onboarding per riferimento

---

### 3️⃣ IT Riceve e Gestisce il Ticket

**Chi:** Reparto IT
**Dove:** Kanban Board → Colonna "To Do"

**IT può:**

1. **Visualizzare** tutte le dotazioni richieste nel ticket
2. **Commentare** per aggiornamenti o domande
   - "Ho ordinato il laptop, arriva giovedì"
   - "Serve conferma per la licenza AutoCAD"
3. **Spostare** il ticket nelle colonne (To Do → In Progress → Done)
4. **Assegnare** a sé stesso per prendere in carico
5. **Allegare file** se necessario (es. screenshot configurazioni)
6. **Marcare come completato** quando tutto è pronto

---

### 4️⃣ Tracciamento e Visibilità

**Tutti possono:**

- ✅ Vedere lo stato del ticket nel Kanban Board
- ✅ Vedere i commenti e gli aggiornamenti
- ✅ Ricevere notifiche quando IT completa il ticket
- ✅ Avere storico completo per audit ISO

**HR può:**

- Vedere lo stato dell'onboarding
- Vedere il ticket collegato
- Comunicare con IT tramite commenti

**IT può:**

- Gestire priorità nel Kanban
- Avere visibilità su tutti gli onboarding in arrivo
- Pianificare gli acquisti in anticipo

## 📊 Esempio Pratico

### Scenario: Nuova Sviluppatrice

**1. Federica (HR) crea onboarding per Francesca Sorrentino**

```
Dipendente: Francesca Sorrentino
Manager: Marco Viola (IT)
Data Inizio: 01/02/2026
Sede: Milano
Reparto: IT
Ruolo: Full Stack Developer

Dotazioni:
- Computer: Portatile
- ✓ Cuffie
- ✓ Webcam
- ✓ Schermo aggiuntivo

Software:
- ✓ Microsoft 365
- Visual Studio Code, Docker, Git, Node.js

Accessi:
- VPN, Repository GitHub, Database sviluppo

Note:
- Serve anche mouse wireless e tastiera meccanica
```

**2. Sistema crea automaticamente ticket:**

```
🎫 Ticket #47
Titolo: 🆕 Onboarding: Francesca Sorrentino - Preparazione Dotazioni
Assegnato a: IT
Priorità: HIGH
Scadenza: 31/01/2026
```

**3. Marco (IT) vede il ticket e commenta:**

```
💬 "Ho ordinato il laptop Dell XPS 15.
    Arriva giovedì 30/01.
    Configurerò tutto venerdì."
```

**4. Venerdì Marco sposta il ticket in "Done":**

```
✅ Ticket completato
✓ Laptop configurato
✓ Software installati
✓ Accessi creati
✓ Tutto pronto sulla scrivania
```

**5. Lunedì 01/02 Francesca inizia con tutto pronto! 🎉**

## 🆘 FAQ

### Q: Cosa succede se dimentico di inserire un'informazione?
**R:** Puoi sempre commentare sul ticket! IT riceverà la notifica.

### Q: IT può modificare le dotazioni richieste?
**R:** Sì, IT può commentare e suggerire alternative. La comunicazione avviene tutta nel ticket.

### Q: Il ticket rimane anche dopo che l'onboarding è completato?
**R:** Sì! Il ticket viene mantenuto per audit e storico. Conforme ISO 9001/27001.

### Q: Posso vedere tutti i ticket di onboarding?
**R:** Gli ADMIN vedono tutto. Gli utenti normali vedono i ticket assegnati a loro o al loro reparto.

### Q: Il sistema invia ancora email?
**R:** Sì, il dipendente riceve un'email di benvenuto con le informazioni. Ma la gestione operativa è tutta nel sistema.
